# DESIGN CODEX — リッチネス定義書

広告デザインアワード水準を目標とする、本ジェネレーターの視覚品質基準。
テンプレート実装・AIプロンプト・レビューのすべてがこの基準に従う。
(参考: Awwwards評価軸 Design 40% / Usability 30% / Creativity 20% / Content 10%、2025-26受賞作の共通技法)

## 1. 画面充填とレイヤー(スカスカの禁止)

- **1ビューポートにつき視覚レイヤー3層以上**: ①背景(テクスチャ/グラデーション/巨大背景タイポ) ②アート/メディア ③コンテンツ ④フローティングアクセント
- **200pxを超える「何もない帯」を作らない**。余白は「設計された余白」(罫線・背景語・装飾が支配する空間)のみ許可
- **セクション境界を越える要素**を2セクションに1回以上(ネガティブマージンによるカードのブリード、境界をまたぐアート)
- セクションの継ぎ目は**フラットな直線禁止**を基本とし、斜めカット・弧・重なりで接続する

## 2. タイポグラフィ(主役化)

- 2ビューポートごとに**64px以上のディスプレイ瞬間**を作る
- 1つの見出し内で**ウェイト/スタイル/塗りとアウトラインを混在**させる
- **背景の巨大半透明タイポ**(セクションキーワードの英字/漢字1字)をレイヤーとして使う
- 縦書き・回転90°のランニングラベルをセクション情報(番号/カテゴリ)として常設
- 和文は `palt` + 文節改行(`.lp-nb`)必須。行間: 見出し1.3前後 / 本文1.9前後

## 3. モーション(js/lp-motion.js が提供)

- 全セクションは **`data-motion` によるスタッガード・リビール**で登場する(遅延60-120ms刻み)
- 主要セクションに **`data-parallax` レイヤー1つ以上**(背景アート/巨大タイポを速度差でスクロール)
- 統計数値は **`data-counter` でカウントアップ**
- マーキー・ホバー変形(scale/translate)・ボタンの光沢/矢印スライドを常備
- すべて `prefers-reduced-motion` で無効化される

## 4. 様式別の密度規範

### 日本型・高密度(広告LP)
- ファーストビュー充填率: ロゴ帯+キャッチ+権威バッジ群+ポイント+価格+CTA+ビジュアルで**画面の70%以上を占有**
- 本文ブロックは「見出し+リード+箇条書き+注釈」の4層。**単独の平文パラグラフ禁止**
- 2〜3カラムの密グリッド、リボン/帯/ブラケット装飾見出し、丸数字、マーカー、吹き出しを常用
- 価格・数値は最大級の視覚要素として扱う(赤/アクセント+特大+単位小)
- CTA帯は緊急性テキスト+ボタン+矢印+マイクロコピー(「30秒で完了」等)の複合構成

### リッチ表現(アワード志向)
- 紙×インク+単一アクセントの規律は維持しつつ、**各ビューに1つの「見せ場」**(巨大タイポ/アート/重なり)を必ず置く
- スクロール速度差(パララックス)と登場演出で「ページが呼吸する」感覚を作る
- 罫線・座標ラベル・インデックス番号などの**エディトリアル装置**で余白を設計物に変える

## 5. 禁止スタイル(AI生成物の典型臭)

以下は「AIが作った」と即座に分かる定型パターンのため、テンプレート・AI生成・レビューのすべてで**使用禁止**:

- **片側太ボーダー+角丸**: 2px以上の太さで4辺のうち1辺だけのアクセントボーダー(`border-left: 4px solid ...` 等)を角丸要素に付けること。上下辺のみへの適用も同様に禁止
- 強調の代替手段: 余白とタイポグラフィの階層 / 背景ティント / 2層シャドウ / 全周1pxのヘアラインボーダー / 帯・リボン等の独立した装飾要素
- 例外: CSS三角形ハック(吹き出しの尻尾・矢印の描画)、表組みのヘッダー罫線、角丸のないタブ・下線装飾は対象外

## 6. 検証チェックリスト(スクリーンショット審査)

- [ ] 1280px全画面キャプチャに「白い帯」が存在しない
- [ ] どの1画面を切り出しても3層以上のレイヤーが確認できる
- [ ] 見出しの改行が文節単位である
- [ ] 統計・価格が画面内で最も強い視覚要素になっている(該当セクション)
- [ ] モーション無効環境でもレイアウトが完全に成立する
- [ ] 禁止スタイル(§5: 片側太ボーダー+角丸)が1箇所も存在しない
